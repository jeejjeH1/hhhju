# پارس — مرورگر امن با پشتیبانی اکستنشن (دسکتاپ)

Electron + Chromium. اجرا: `npm install && npm start` — تست: `npm test`

**امنیت:** سندباکس و context isolation، رد پیش‌فرض همه‌ی مجوزها (پرسش از کاربر)، ارتقای خودکار HTTPS،
رد گواهی نامعتبر، مسدودسازی ردیاب‌ها، Sec-GPC/DNT، کوتاه‌سازی Referer، جلوگیری از نشت IP در WebRTC،
تب خصوصی با سشن جدا، پاک‌سازی هنگام خروج، رابط بدون دسترسی به شبکه.

**اکستنشن:** نصب از فروشگاه وب کروم (لینک/شناسه)، فایل CRX یا پوشه‌ی unpacked؛ با نمایش مجوزها در پنجره‌ی بومی.
محدودیت: Electron فقط بخشی از APIهای `chrome.*` را پشتیبانی می‌کند.
